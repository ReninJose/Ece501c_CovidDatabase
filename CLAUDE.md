# Project Setup
1. Create a python virtual environment .venv
2. Activate your env
3. Install packages from requirement.txt
4. Create .env file and add your census api key. API key can be requested at: https://api.census.gov/data/key_signup.html
5. Check for database/covid.db, if exist, remove that file.
